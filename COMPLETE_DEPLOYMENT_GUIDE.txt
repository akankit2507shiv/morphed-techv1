📋 COMPLETE DEPLOYMENT WALKTHROUGH

Follow these steps EXACTLY in order:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: CREATE GITHUB REPOSITORY

1. Open browser and go to: https://github.com/new

2. Fill in:
   Repository name: morphed-tech
   Description: Data Engineering Learning Platform
   Visibility: ✅ Public (recommended) or Private
   
   ⚠️ IMPORTANT: DO NOT check these boxes:
   ❌ Add a README file
   ❌ Add .gitignore
   ❌ Choose a license

3. Click "Create repository"

4. You'll see a page with commands. COPY the repository URL.
   It looks like: https://github.com/YOUR_USERNAME/morphed-tech.git

STEP 2: PUSH CODE TO GITHUB

Open Terminal and run these commands ONE BY ONE:

✅ Success message: "Branch 'main' set up to track remote branch 'main'"

STEP 3: DEPLOY BACKEND TO RENDER

1. Go to: https://render.com

2. Click "Get Started" or "Sign Up"

3. Choose "Sign up with GitHub"

4. Authorize Render to access your GitHub

5. After login, click "New +" button (top right)

6. Select "Web Service"

7. Click "Connect a repository"

8. Find and select "morphed-tech" repository

9. Configure the service:
   
   Name: morphed-tech-backend
   Region: Choose closest to you
   Branch: main
   Root Directory: (leave empty)
   Environment: Node
   Build Command: npm install
   Start Command: npm start
   
   Instance Type: Free

10. Click "Advanced" to add Environment Variables

11. Add these variables ONE BY ONE (click "Add Environment Variable"):

    Key: PORT
    Value: 10000

    Key: NODE_ENV
    Value: production

    Key: JWT_SECRET
    Value: morphed_tech_production_jwt_secret_key_2024_secure

    Key: ADMIN_EMAIL
    Value: !Mahadev007!@gmail.com

    Key: ADMIN_PASSWORD
    Value: !Mahakal007!@

    Key: UPI_ID
    Value: morphedtech@paytm

    Key: UPI_NAME
    Value: Morphed Tech

    Key: COURSE_PRICE
    Value: 1111

12. Click "Create Web Service"

13. Wait 5-10 minutes. Watch the logs.

14. When you see "✅ Live" at the top, COPY the URL
    Example: https://morphed-tech-backend.onrender.com

15. Test backend: Visit https://YOUR-BACKEND-URL.onrender.com/health
    Should show: {"status":"ok","timestamp":"..."}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4: UPDATE API URLS IN CODE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In Terminal, run:

./deploy.sh https://YOUR-BACKEND-URL.onrender.com

STEP 5: DEPLOY FRONTEND TO VERCEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://vercel.com

2. Click "Sign Up" or "Login"

3. Choose "Continue with GitHub"

4. Authorize Vercel

5. After login, click "Add New..." → "Project"

6. Click "Import" next to your "morphed-tech" repository

7. Configure:
   
   Project Name: morphed-tech (or leave default)
   Framework Preset: Other
   Root Directory: ./
   Build Command: (leave empty)
   Output Directory: .
   Install Command: (leave empty)

8. Click "Deploy"

9. Wait 2-3 minutes

10. When you see "🎉 Congratulations!", click "Continue to Dashboard"

11. COPY your deployment URL
    Example: https://morphed-tech.vercel.app
    or: https://morphed-tech-git-main-yourname.vercel.app

12. Click on the URL to test - you should see your landing page

STEP 6: UPDATE CORS IN BACKEND
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open server.js in your code editor

2. Find line 12-18 (CORS configuration)

3. Replace the corsOptions with:

  origin: [
    'https://YOUR-FRONTEND.vercel.app',
    'https://YOUR-FRONTEND-*.vercel.app',
    'http://localhost:5000'
  ],
  credentials: true,
  optionsSuccessStatus: 200
};

Example:
const corsOptions = {
  origin: [
    'https://morphed-tech.vercel.app',
    'https://morphed-tech-*.vercel.app',
    'http://localhost:5000'
  ],
  credentials: true,
  optionsSuccessStatus: 200
};

4. Save the file

5. Push to GitHub:

git add server.js
git commit -m "Update CORS for production"
git push

6. Go to Render dashboard and wait 2-3 minutes for auto-redeploy

7. Check logs to confirm deployment
