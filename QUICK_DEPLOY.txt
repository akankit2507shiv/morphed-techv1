📋 DEPLOYMENT CHECKLIST (15 minutes total)

┌─────────────────────────────────────────────────────────────┐
│ STEP 1: DEPLOY BACKEND (5 min)                             │
└─────────────────────────────────────────────────────────────┘

  1. Go to: https://render.com
  2. Sign up with GitHub
  3. Click "New +" → "Web Service"
  4. Connect GitHub repo
  5. Configure:
     • Name: morphed-tech-backend
     • Environment: Node
     • Build: npm install
     • Start: npm start
  6. Add Environment Variables (copy from .env.production)
  7. Click "Create Web Service"
  8. ⏰ Wait 5-10 minutes
  9. ✅ Copy backend URL

┌─────────────────────────────────────────────────────────────┐
│ STEP 2: UPDATE API URLS (2 min)                            │
└─────────────────────────────────────────────────────────────┘

  Run this command:
  
  ./deploy.sh https://YOUR-BACKEND-URL.onrender.com
  
  This updates all HTML files automatically.

┌─────────────────────────────────────────────────────────────┐
│ STEP 3: DEPLOY FRONTEND (3 min)                            │
└─────────────────────────────────────────────────────────────┘

  1. Go to: https://vercel.com
  2. Sign up with GitHub
  3. Click "Add New" → "Project"
  4. Import GitHub repo
  5. Configure:
     • Framework: Other
     • Build: (empty)
     • Output: .
  6. Click "Deploy"
  7. ⏰ Wait 2-3 minutes
  8. ✅ Copy frontend URL

┌─────────────────────────────────────────────────────────────┐
│ STEP 4: UPDATE CORS (2 min)                                │
└─────────────────────────────────────────────────────────────┘

  1. Open server.js
  2. Update CORS with your Vercel URL
  3. git add server.js
  4. git commit -m "Update CORS"
  5. git push
  6. ⏰ Wait 2-3 minutes for auto-redeploy
