🔧 STEP 1: DEPLOY BACKEND (5 minutes)

   Platform: Render.com
   URL: https://render.com

   Actions:
   1. Sign up with GitHub
   2. Create "Web Service"
   3. Connect this repository
   4. Configure:
      - Name: morphed-tech-backend
      - Environment: Node
      - Build: npm install
      - Start: npm start
   5. Copy environment variables from .env.production
   6. Deploy
   7. COPY YOUR BACKEND URL

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔄 STEP 2: UPDATE API URLS (2 minutes)

   Run this command:

   ./deploy.sh https://YOUR-BACKEND-URL.onrender.com

   This automatically updates all HTML files with your backend URL.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🌐 STEP 3: DEPLOY FRONTEND (3 minutes)

   Platform: Vercel
   URL: https://vercel.com

   Actions:
   1. Sign up with GitHub
   2. Import this repository
   3. Configure:
      - Framework: Other
      - Build: (empty)
      - Output: .
   4. Deploy
   5. COPY YOUR FRONTEND URL

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔐 STEP 4: UPDATE CORS (2 minutes)

   1. Open server.js
   2. Find line ~12 (CORS configuration)
   3. Replace with your Vercel URL:

      const corsOptions = {
        origin: [
          'https://YOUR-FRONTEND.vercel.app',
          'https://YOUR-FRONTEND-*.vercel.app'
        ],
        credentials: true,
        optionsSuccessStatus: 200
      };

   4. Save and push:
      git add server.js
      git commit -m "Update CORS"
      git push

   5. Wait 2-3 minutes for auto-redeploy
